# PhysicsMap — физика и телеметрия ACC Shared Memory

Документация полей `PhysicsMap` из крейта [`acc_shared_memory_rs`](https://crates.io/crates/acc_shared_memory_rs) (v0.8.0).

Высокочастотная телеметрия и динамика машины Assetto Corsa Competizione. Данные обновляются каждый пакет shared memory и доступны через `ACCMap.physics`.

Типы вложенных структур:

| Тип | Поля | Назначение |
| --- | --- | --- |
| `Vector3f` | `x`, `y`, `z` | 3D-вектор (скорость, силы, направления) |
| `Wheels` | `front_left`, `front_right`, `rear_left`, `rear_right` | Значение по каждому колесу |
| `ContactPoint` | те же 4 колеса, каждое — `Vector3f` | Точки/векторы контакта шин с трассой |
| `CarDamage` | `front`, `rear`, `left`, `right`, `center` | Повреждения кузова по зонам |

---

## Метаданные

| Имя в коде | На русском | Описание |
| --- | --- | --- |
| `packet_id` | Идентификатор пакета | Уникальный номер телеметрического пакета; увеличивается с каждым обновлением. Полезно для детекта «свежих» данных. |

## Ввод пилота

| Имя в коде | На русском | Описание |
| --- | --- | --- |
| `gas` | Газ (педаль) | Положение педали газа: `0.0` — не нажата, `1.0` — в пол. |
| `brake` | Тормоз (педаль) | Положение педали тормоза: `0.0` — не нажата, `1.0` — в пол. |
| `clutch` | Сцепление | Положение педали сцепления: `0.0` — не нажата, `1.0` — в пол. |
| `steer_angle` | Угол руля | Угол поворота руля в градусах. |
| `gear` | Передача | Текущая передача: `0` — нейтраль, `1` — первая и т.д. (отрицательные — задняя). |
| `rpm` | Обороты двигателя | Частота вращения коленвала, об/мин. |
| `autoshifter_on` | Автопереключение | Включён ли автоматический шифтер. |
| `ignition_on` | Зажигание | Включено ли зажигание. |
| `starter_engine_on` | Стартер | Крутит ли стартер двигатель. |
| `is_engine_running` | Двигатель работает | Запущен ли двигатель в данный момент. |

## Динамика и движение

| Имя в коде | На русском | Описание |
| --- | --- | --- |
| `speed_kmh` | Скорость | Скорость автомобиля, км/ч. |
| `velocity` | Скорость (мир) | Вектор скорости в мировых координатах (`Vector3f`: x, y, z). |
| `local_velocity` | Скорость (локальная) | Вектор скорости в локальной системе машины (`Vector3f`). |
| `local_angular_vel` | Угловая скорость | Вектор угловой скорости в локальных координатах (`Vector3f`), рад/с. |
| `g_force` | Перегрузки (G) | Вектор перегрузок (`Vector3f`: продольная, вертикальная, боковая). |
| `heading` | Курс | Ориентация по курсу (yaw) в радианах. |
| `pitch` | Тангаж | Наклон носа вверх/вниз в радианах. |
| `roll` | Крен | Наклон влево/вправо в радианах. |
| `final_ff` | Сила обратной связи | Итоговое значение force feedback на руль. |

## Колёса и шины

| Имя в коде | На русском | Описание |
| --- | --- | --- |
| `wheel_slip` | Проскальзывание колеса | Величина проскальзывания по каждому колесу (`Wheels`). |
| `wheel_pressure` | Давление в шинах | Давление в шинах по колёсам, psi (`Wheels`). |
| `wheel_angular_speed` | Угловая скорость колеса | Угловая скорость вращения каждого колеса, рад/с (`Wheels`). |
| `tyre_core_temp` | Температура ядра шины | Температура корда/ядра шины по колёсам, °C (`Wheels`). |
| `suspension_travel` | Ход подвески | Ход подвески по колёсам, мм (`Wheels`). |
| `brake_temp` | Температура тормозов | Температура тормозных механизмов по колёсам, °C (`Wheels`). |
| `brake_pressure` | Давление в тормозах | Давление в тормозной системе по колёсам, бар (`Wheels`). |
| `suspension_damage` | Повреждение подвески | Степень повреждения подвески: `0.0` — цела, `1.0` — полностью повреждена (`Wheels`). |
| `slip_ratio` | Коэффициент скольжения | Slip ratio шины по колёсам (`Wheels`). |
| `slip_angle` | Угол увода | Угол увода шины по колёсам, градусы (`Wheels`). |
| `pad_life` | Износ колодок | Остаточный ресурс тормозных колодок, % (`Wheels`). |
| `disc_life` | Износ дисков | Остаточный ресурс тормозных дисков, % (`Wheels`). |
| `front_brake_compound` | Состав передних колодок | Индекс компаунда передних тормозных колодок. |
| `rear_brake_compound` | Состав задних колодок | Индекс компаунда задних тормозных колодок. |

## Контакт шин с трассой (3D)

| Имя в коде | На русском | Описание |
| --- | --- | --- |
| `tyre_contact_point` | Точка контакта шины | 3D-позиция точки касания каждой шины с поверхностью (`ContactPoint`). |
| `tyre_contact_normal` | Нормаль контакта | Нормаль поверхности в точке контакта каждой шины (`ContactPoint`). |
| `tyre_contact_heading` | Направление контакта | Вектор направления контакта каждой шины (`ContactPoint`). |

## Состояние автомобиля

| Имя в коде | На русском | Описание |
| --- | --- | --- |
| `fuel` | Топливо | Текущий уровень топлива, литры. |
| `tc` | Traction Control | Уровень/настройка системы контроля тяги (TC). |
| `abs` | ABS | Уровень/настройка антиблокировочной системы. |
| `pit_limiter_on` | Пит-лимитер | Активен ли ограничитель скорости в боксах. |
| `turbo_boost` | Наддув турбо | Давление наддува турбокомпрессора, бар. |
| `air_temp` | Температура воздуха | Температура окружающего воздуха, °C. |
| `road_temp` | Температура трассы | Температура покрытия, °C. |
| `water_temp` | Температура ОЖ | Температура охлаждающей жидкости двигателя, °C. |
| `car_damage` | Повреждения кузова | Повреждения по зонам: перед, зад, лево, право, центр (`CarDamage`, обычно `0.0`…`1.0`). |
| `is_ai_controlled` | Управление ИИ | Управляется ли машина ИИ, а не игроком. |
| `brake_bias` | Баланс тормозов | Доля тормозного усилия на переднюю ось, %. |

| `car_damage.center` | Повреждение центра | Повреждение центральной части / шасси. |

## Вспомогательные методы

| Метод | На русском | Описание |
| --- | --- | --- |
| `is_equal(&other)` | Сравнение пакетов | Сравнивает два `PhysicsMap` по `suspension_travel` — способ понять, что пришли новые данные. |
| `is_moving()` | Машина едет | `true`, если `speed_kmh > 1.0`. |
| `is_on_track()` | На трассе | `true`, если пит-лимитер выключен (`!pit_limiter_on`). |
| `max_tyre_temp()` | Макс. температура шин | Максимум среди четырёх `tyre_core_temp`. |
| `max_brake_temp()` | Макс. температура тормозов | Максимум среди четырёх `brake_temp`. |

## Что полезно для Runsheet

Поля, наиболее релевантные для записи заезда и разбора круга:

| Сценарий | Поля |
| --- | --- |
| Траектория ввода (газ / тормоз / руль / скорость) | `gas`, `brake`, `steer_angle`, `speed_kmh`, `clutch`, `gear`, `rpm` |
| Состояние заезда | `fuel`, `pit_limiter_on`, `is_engine_running`, `is_ai_controlled` |
| Шины и тормоза | `tyre_core_temp`, `wheel_pressure`, `brake_temp`, `pad_life`, `disc_life` |
| Настройки электроники | `tc`, `abs`, `brake_bias` |
| Условия трассы | `air_temp`, `road_temp` |
| Повреждения | `car_damage`, `suspension_damage` |
| Позиция / ориентация (линия проезда) | `velocity` / `local_velocity`, `heading`, `pitch`, `roll`, `tyre_contact_point` |
| Детект обновления | `packet_id`, `is_equal()` |
